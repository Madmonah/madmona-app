# 🩺 WhatsApp Messages — قطاع العيادات (clinic_leads)

مبني على نفس هيكل `02_WHATSAPP_MESSAGES.md`، بعمولة العيادات الرسمية (محمد، 1 أغسطس 2026): **10%**.

⚠️ **ده التيمبلت اللي بالفعل مُفعّل تلقائيًا** عن طريق `enqueue_clinic_outreach_batch()` +
كرون `clinic-outreach-daily` (بيبعت لغاية 25 عيادة يوميًا من جدول `clinic_leads`,
status='new', has_whatsapp=true, contact_attempts<2, بالأولوية لتقييم 4.5+ و50+ مراجعة).
كان بيقول "العمولة 5%" غلط — **اتصلح دلوقتي لـ10%** (1 أغسطس 2026).

---

## VARIANT 1 (الأوتوماتيك — اللي فعلاً بيتبعت)

```
السلام عليكم [اسم العيادة] 🩺

من فريق *مضمونة* — منصة جديدة بتنمو بسرعة في مصر بتشغّل عيادات وبنوصّلكوا
مرضى جداد بحجز مضمون بعربون.

تقييم عيادتكوا ممتاز في [التخصص]، وحبّينا نعرض عليكوا نموذج فعلي لعيادة
شغّالة معانا — ٣ فروع · ٤ أطباء · حجز فوري · حضور بالموقع · أرباح كل فرع.

شُف الـ Demo: https://madmonacairo.com/demo/clinic/polyclinic-model

العمولة ١٠٪ بس على الحجز الفعلي · بدون رسوم اشتراك أو تفعيل.
```

## VARIANT 2: نسخة أوضح للعيادات المتردّدة (يدوي، لو حبيت ترد بنفسك بعد رد أولي)

```
أهلاً [اسم العيادة] 👋

شكرًا لاهتمامكم بمضمونة. عشان الصورة تكون واضحة:

✅ حجز فوري من المريض على المنصة، ومعاه عربون بيضمن جديّة الموعد
✅ العمولة 10% بس، وبتتحصّل بعد الحجز الفعلي — مفيش رسوم اشتراك ولا تفعيل
✅ دعم 24/7 لو حصلت أي مشكلة في الحجوزات
✅ صفحة عيادة جاهزة بالتخصصات والأطباء والمواعيد المتاحة

تحبوا نجهز لكم صفحة تجريبية دلوقتي؟ محتاجين بس أسماء الأطباء والتخصصات والمواعيد المتاحة.
```

## 📋 ملاحظات تشغيلية

- [ ] `contact_attempts < 2` = العيادة بتتبعتلها الرسالة مرتين بالحد الأقصى تلقائيًا، بعدها status يفضل 'contacted' وتوقف
- [ ] الأولوية للعيادات الأعلى تقييم (4.5+ ومراجعات 50+) — دي بتتبعتلها الأول في كل batch
- [ ] الكرون بيبعت 25 عيادة/يوم افتراضيًا (`p_limit default 25`) — ممكن تزوّد العدد بتمرير رقم مختلف يدويًا
- [ ] لو عايز تبعت دفعة يدوية دلوقتي: `select enqueue_clinic_outreach_batch(25);` (لازم إذن صريح "ابعت" الأول)
- [ ] عدد العيادات الحالي في الجدول: 101 (44 أصلية + 57 من بحث جوجل بليسز 31 يوليو/1 أغسطس 2026)
