# 📚 طابور «قصة حقيقية من عالم البيزنس» — أمر محمد ١٣/٩/٢٠٢٦

> محمد: «أكتر حاجة بتجيب تفاعل قصص حقيقية من البيزنس — عايزين منها كتير، وده مايمنعش نلاقي فرصة نعلن فيها عن مضمونة، ونوّع بين شركات عالمية وشركات أجنبية وشخصيات عالمية وشخصيات مصرية».

## القواعد
- وقائع **موثّقة ومشهورة بس** — صفر أرقام مالية مخترعة (سنين وأسماء فقط).
- القالب: نوار (`build-noir.js`) · راوي **بهجت V2 + المصرية القاهرية** (لهجتي من كروم محمد — لو خارجة: القصة تستنى، مفيش Edge).
- كل قصة: ٩–١١ جملة · مشهد مضمونة واحد قبل الآخر (ربط طبيعي بموديول موجود) · CTA سؤال يجيب كومنتات.
- كابشن **مختلف** لكل منصة · كل اللينكات → `/start` بـ`utm_content=<slug>` · كومنت أول على فيسبوك/يوتيوب/تيك توك.
- **التناوب:** عالمية → أجنبية → شخصية عالمية → شخصية مصرية → … (ماتتكررش فئة قبل ما الباقي ياخد دوره).

## ملاحظات تشغيل
- كل قصة = `_add_bizN.cjs` (كونفيج + `vo-<slug>.txt` + ٨ كابشنات مختلفة) → `build-noir.js` → لهجتي (بهجت) → `_fit_noir.cjs` → تسجيل → overlay الفريم الأول → شورتس أول (+كومنت) → تيك توك (+كومنت) → إنستجرام → ثريدز → تليجرام → فيسبوك بروفايل (+كومنت) → جروبات في حصة اليوم.
- **الإيميل (١٣/٩):** كل قصة بتتحوّل كمان لرسالة **يومية** في نشرة «قصة حقيقية» (محمد: كل يوم مش كل أسبوع) (`docs/marketing/email-marketing.md`).
