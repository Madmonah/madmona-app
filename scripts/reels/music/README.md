# Music Folder

Place royalty-free MP3 files here named `default.mp3`.

The renderer will use this as background music for all reels.

## Free royalty-free music sources:

- **YouTube Audio Library** — https://studio.youtube.com/channel/UC/music
- **Pixabay Music** — https://pixabay.com/music/ (no signup needed)
- **Free Music Archive** — https://freemusicarchive.org/
- **Bensound** — https://www.bensound.com/

## Recommended search terms for Madmona reels:

- "upbeat corporate"
- "modern arabic"
- "lifestyle background"
- "lo-fi commercial"
- "energetic positive"

## Files to add:

- `default.mp3` — main background music (used for all reels until per-reel music is implemented)
- Optionally: `cars.mp3`, `office.mp3`, `lifestyle.mp3` — category-specific

If no music file is present, reels will be rendered silent (you can add audio in Instagram).
