# wa-web — خدمة المارد على واتساب ويب الرسمي

خدمة **تانية جنب `wa-service`** — مش بديلة ليها.

| الرقم | الخدمة | السبب |
|---|---|---|
| `201002229982` | `wa-service` (Baileys) | مربوط من شهور وبيسلّم — 🔴 **ماينفعش يتلمس** |
| `201114621551` · `201026222337` | `wa-web` (هنا) | أرقام جديدة |

## ليه المكتبة دي
Baileys بيعيد بناء بروتوكول واتساب من الصفر. `whatsapp-web.js` بتشغّل
**صفحة واتساب ويب الرسمية** في متصفح مخفي وتتحكم فيها — فالتليفون يفضل
شغال عادي (جهاز مرتبط زي أي واتساب ويب)، على عكس Cloud API اللي بياخد الرقم.

اتجربت في معمل معزول قبل ما تتبني: ربطت رقم جديد وبعتت **ووصلت واتقريت**.
(OpenWA اتجرب كمان وفشل في الإقلاع مرتين — الحقن بتاعه بيتكسر مع تحديثات
واتساب ويب.)

## العقد
**نفس `wa-service` بالحرف** — نفس المسارات، نفس شكل حمولة الويبهوك، نفس
هيدر السر. التطبيق مايفرقش بين الاتنين.

```
GET  /health                 حالة الجلسات
GET  /qr?session=<id>        صفحة الـQR
GET  /sessions               قايمة الجلسات
POST /sessions               { session, label }   ← ضيف رقم
DEL  /sessions/:id           فك ربط
POST /send                   { to, jid, text, session } → { ok, wa_message_id, session }
```

## متغيرات رايلواي
```
APP_WEBHOOK_URL = https://www.madmonacairo.com/api/whatsapp/baileys
SHARED_SECRET   = نفس السر بتاع wa-service
AUTH_DIR        = /data/auth        ← لازم Volume على /data
SESSIONS        = 201114621551:المساعد,201026222337:محمد ناصف
```

## النشر (خدمة جديدة على رايلواي)
1. `+ New` ← GitHub Repo ← `Madmonah/madmona-app`
2. Settings → **Root Directory = `wa-web`** · Branch = `main`
3. ضيف **Volume** على `/data`
4. المتغيرات فوق
5. على Vercel: `WA_WEB_SERVICE_URL = <رابط الخدمة دي>`
6. افتح `/qr?session=201026222337` واسكان

## التوجيه
مين بيروح فين متحدد في `wa_number_configs.transport` (`baileys` | `web`).
نقل رقم بين الخدمتين = **تحديث صف واحد** — من غير نشر ومن غير ما التاني يتهز.
ولو `WA_WEB_SERVICE_URL` مش متظبطة، كل الأرقام بتفضل على الخدمة الأصلية.

## فروق مقصودة عن wa-service
- **مفيش fallback لرقم تاني** لو الجلسة مقفولة. `wa-service` بيعمل كده،
  وده بيخلّي عميل يجيله رد من رقم ماكلّمهوش. هنا: الرقم المطلوب أو خطأ واضح.
- الميديا الواردة مرحلة تانية — النص أولاً.
- بيقفل العميل القديم قبل أي إعادة اتصال (درس من `fa02352`).
